## 四、合理性分析

### ✅ 合理之处

#### 1. 理论创新有据可依

- 世界模型（World-in-World + DreamerV3）是 AI 前沿，迁移到知识服务领域有学理基础
- SKWM 七元组框架对应策划案，有完整的理论推演链条
- "闭环任务成功率"评测哲学直接呼应 World-in-World 论文的核心贡献
- 概念对齐表（World-in-World → SKWM）提供了清晰的映射逻辑

#### 2. 场景选择有独特优势

- 中阿文旅 = 北二外"外语+旅游"特色的天然落地场景
- 4,833篇阿语核心库 + 21,042条三语术语 = 数据壁垒，国内几乎独有
- 89年时序切片提供了纵向演化分析的基础
- 国内几乎没有"世界模型驱动图书馆服务"的同类研究，差异化明显

#### 3. 工程实现完整度高

- 五层架构全部实现（数据→知识组织→智能分析→智能体→应用）
- 前后端联通（FastAPI + Next.js + Neo4j）
- 30项系统测试通过率 83.3%
- 39词实验命中率 64.1%，有明确改进方向
- 飞书推送 + Obsidian 沉淀形成完整服务闭环

#### 4. 方法可复制

- SKWM 框架不绑定特定领域，换一个数据源就能推广
- 闭环规划算法是通用的 propose→simulate→revise 范式
- 七元组定义是领域无关的抽象

#### 5. 政策契合

- 一带一路 + 中阿合作论坛 = 国家战略需求
- 高校图书馆智能化 = 教育部"新文科"方向
- 区域国别研究 = 2023年成为一级学科后的热点

### ⚠️ 需要补强的地方

#### 1. 实验说服力不足（最关键）

| 问题 | 现状 | 需要 |
|------|------|------|
| 闭环评测 | 仅跑了2年回测 | 需要5年+回测，画 learning curve |
| 对比实验 | 无 baseline | 需要对比传统方法（纯 XGBoost、纯 RAG、无闭环） |
| 用户实验 | 无 | 需要真实用户（教师/学生）使用反馈 |
| 统计显著性 | 无 | 需要多次实验 + p-value |
| 查询实验 | 命中率64.1% | 需提升到80%+，且补充阿拉伯语查询 |

#### 2. RSSM 内核未真正训练

- `skwm_world_model.py` 已有骨架，但 PyTorch 未安装、模型未训练
- 论文如果声称有"世界模型内核"，必须有训练好的模型和预测结果
- **建议**：要么尽快训练出结果，要么论文中只提"外壳"（闭环规划），把 RSSM 作为 future work

#### 3. 中阿文旅特色需深化

- 实验显示"区域国别"命中率仅25%，"学术服务"0%
- 阿拉伯国家数据覆盖严重不足（阿联酋、埃及、中东研究全0）

- **建议**：补充阿拉伯国家文献，平衡中英文数据
