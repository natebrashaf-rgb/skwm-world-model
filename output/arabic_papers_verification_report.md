## 验证方法说明

### CrossRef API
- 官方DOI注册机构
- 验证DOI是否真实注册
- 返回标题、年份等元数据
- 准确率: 100%（对于已注册DOI）

### OpenAlex API
- 开放学术数据库
- 支持标题搜索
- 返回相关度评分
- 准确率: 依赖标题匹配质量

### 验证流程
1. 对有DOI的文献：调用CrossRef API验证
2. 对无DOI的文献：使用OpenAlex标题搜索
3. 对验证失败的文献：重试3次
4. 生成验证报告
