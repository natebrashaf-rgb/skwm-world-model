## Task C: 数据接入模型与对照实验

### 实验设计

比较三个模型版本：
- **V1 原始模型**: 不含阿语文献 (12,152 篇)
- **V2 含阿语模型**: 加入 27 篇阿语文献 (12,179 篇)
- **V3 跨语言模型**: 带语言标记（概念验证）

### 实验结果

#### 1. 主题趋势变化分析

| 指标 | 结果 |
|------|------|
| Top主题 Jaccard 相似度 | **1.000** (完全一致) |
| 2020/2022/2024 年 Top20 | 无变化 |
| 新增主题数 | **0** |

**结论**: 加入阿语文献后，主题热度排序和趋势**未发生实质变化**。

#### 2. 阿语文献特征

| 指标 | 数值 |
|------|------|
| 阿语文献总数 | 27 篇 |
| has_pdf=true | 15 篇 |
| 有全文可分析 | **9 篇** |
| 文旅相关 | 13 篇 (48%) |
| 年份覆盖 | 8 年 (2012, 2017, 2019-2022, 2024-2025) |
| 年份集中度 | 2020-2025 占 74% |

#### 3. 关键主题趋势对比

| 主题 | 原版热度 | 含阿语热度 | 差异 |
|------|----------|------------|------|
| 旅游 | 45,375 | 45,375 | 0.0% |
| 目的地 | 10,066 | 10,066 | 0.0% |

**结论**: 阿语文献对整体主题热度的贡献微乎其微（<0.1%）。

### Task C 回答的三个问题

| 问题 | 回答 | 证据 |
|------|------|------|
| **加入阿语文献后，主题趋势是否变化？** | **否** | Jaccard=1.0，Top20完全一致 |
| **阿语文献是否改变跨语言主题映射？** | **否** | 新增主题数=0 |
| **阿语是否适合单独建模？** | **否** | 样本量27篇<50，年份集中 |

### Task C 综合结论

> 阿语文献数量少（27篇）且年份集中（74%在2020-2025），**不适合单独RSSM建模**。
> 但应保留其对跨语言模型和主题解释的贡献，特别是阿拉伯文化、伊斯兰文化等本土议题。

### Task D 核心发现

#### 1. 共同主题
阿语和英文文献都关注：
- 教育（阿语10篇，英文52篇）
- 历史（阿语4篇，英文13篇）

#### 2. 阿语独有/更突出主题
- **阿拉伯文化** (14篇): 阿拉伯身份认同、语言、书法、手稿
- **文化遗产** (9篇): 物质遗产、手稿、医学遗产、建筑遗产
- **伊斯兰文化** (7篇): 伊斯兰教法、宗教教育、医学遗产
- **数字化** (9篇): 数字人文、智能刺绣、数字化保护

#### 3. 覆盖差异分析
- **英文覆盖但阿语较少**: 旅游/遗产（258 vs 0）、文化研究（90 vs 0）
- **阿语覆盖但英文较少**: 阿拉伯文化（14 vs 0）、数字化（9 vs 0）、文化遗产（9 vs 0）

**差异原因**: 
- 不是出版生态差异，而是**研究传统差异**
- 阿语文献更关注本土文化认同、物质遗产和宗教议题
- 英文文献更关注国际旅游和跨文化交流

## 综合结论与建议

### 1. 阿语文献的价值

| 维度 | 评估 |
|------|------|
| 数量 | 不足（27篇） |
| 全文可用 | 9篇（33%） |
| 质量 | 中等（13篇文旅相关） |
| 独特性 | 高（阿拉伯文化、伊斯兰文化、物质遗产视角） |
| 时序性 | 弱（年份集中，无法构建完整序列） |

### 2. 对世界模型的影响

- **主题趋势**: 无实质影响（Jaccard=1.0）
- **跨语言映射**: 无新增主题
- **独立建模**: 不适合（样本量不足）

### 3. 建议

#### 短期（当前项目）
- 保留阿语文献作为跨语言模型的补充
- 在主题解释中纳入阿拉伯文化、伊斯兰文化、物质遗产视角
- 不做阿语独立RSSM

#### 中期（数据扩充）
- 继续收集阿语文献，目标≥100篇
- 重点补充2015年前的文献，平衡年份分布
- 增加全文获取，当前15篇has_pdf中仅9篇成功提取

#### 长期（模型升级）
- 当阿语文献≥200篇且年份分布均匀时，考虑独立RSSM
- 构建跨语言主题对齐模型（阿语-英语-中文）
