# RSSM V3 五随机种子真实数据实验报告

## 实验结论

本实验确认仓库中的 RSSM V3 **确实接入真实项目数据并能够完成五个随机种子的重复训练**。训练数据来自 `data/state_vectors.json` 和 `data/B1_文献主表.json`，经项目内 `BridgeKnowledgeWorldModel` 加载；共形成 **1,700 条真实数据滑动窗口序列**，训练年份为 1995–2019，切分年份为 2020，未使用随机生成的观测数据。

从训练稳定性看，五个种子均完成 1,200 个训练步骤，loss 全程保持有限值并明显下降，因此**代码和训练流程具有可重复运行性**。但从预测质量看，当前 V3 的 Spearman 相关性较低，P@10/Recall@10 也较弱；本实验只证明了“真实数据训练与评测流程可运行”，不能据此宣称 RSSM V3 已优于基线。

## 五种子汇总结果

下表中的 MAE、RMSE、Spearman、P@10、Recall@10 和 NDCG@10 均先对每个种子的 5 个评测年份取平均，再在五个种子之间计算均值和标准差。P@10 与 Recall@10 在本实验定义下均取预测 Top-10 与实际 Top-10 的交集比例，因此数值相同。

| Horizon | MAE 均值 ± SD | Spearman 均值 ± SD | P@10 均值 ± SD | Recall@10 均值 ± SD | NDCG@10 均值 ± SD |
|---:|---:|---:|---:|---:|---:|
| 1 年 | 21.353 ± 0.349 | 0.062 ± 0.039 | 0.060 ± 0.032 | 0.060 ± 0.032 | 0.099 ± 0.026 |
| 3 年 | 23.150 ± 0.487 | 0.080 ± 0.045 | 0.048 ± 0.023 | 0.048 ± 0.023 | 0.149 ± 0.034 |
| 5 年 | 24.867 ± 0.358 | 0.038 ± 0.048 | 0.068 ± 0.046 | 0.068 ± 0.046 | 0.162 ± 0.031 |

| 3 年 | [22.545, 23.755] | [0.023, 0.136] | [0.020, 0.076] | [0.020, 0.076] | [0.106, 0.192] |

需要注意，以上置信区间描述的是**五个随机种子造成的模型结果不确定性**，不是把所有主题和年份评测点当作独立样本后的区间。种子数量只有 5 个，因此区间适合用于稳定性报告，不应解释为最终总体性能的精确估计。

## 复现方式与产物

实验入口为 `run_rssm_v3_five_seeds.py`，默认执行命令为：

```bash
python3 run_rssm_v3_five_seeds.py --steps 1200 --batch 128
```

实验目录 `output/rssm_training_v3/five_seeds/` 保存了配置、汇总统计、五个检查点、五份训练日志、五份预测文件、完整预测明细和运行日志。主要文件如下：

| 文件 | 内容 |
|---|---|
| `experiment_config.json` | 数据、时间切分、模型和种子配置 |
| `five_seed_summary.json` | 均值、标准差、95% CI、最好/最差种子 |
| `training_log_seed_*.json` | 每个种子的逐步 loss 日志 |
| `predictions_seed_*.json` | 每个种子的逐评测年份指标 |
| `all_predictions.json` | 所有种子的预测评测明细 |
| `model_seed_*.pt` | 每个随机种子的模型检查点 |
| `run.log` | 完整运行日志 |

## 方法限制与下一步

当前实验的 RSSM V3 评估使用每个种子单独进行随机先验 rollout，因此 `uncertainty` 字段在单模型评估中不作为有效集成置信度使用；真正的不确定性区间应在同一输入下进行多次 rollout，或明确把五个种子作为 ensemble 后再计算预测分布。此外，P@10、Recall@10 的定义目前是“实际增长 Top-10”，需要在论文中固定正例阈值或任务定义，避免与标准信息检索 Recall@10 混用。

最重要的是，当前结果还缺少同一评测窗口下的基线结果表。下一步应以完全相同的训练/评测年份、主题集合和指标定义运行 last、moving-average、linear、XGBoost/GRU 等基线，并进行配对比较。只有在修正评估代码、统一模型接口并完成基线比较后，才能判断 RSSM V3 是否具有论文级效果可行性。
