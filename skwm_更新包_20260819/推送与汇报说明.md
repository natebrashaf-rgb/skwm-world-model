# 推送到 GitHub 说明 (skwm-world-model)

## 一、本包内容
`experiments/` — 完整实验流水线(新增目录, 不覆盖仓库主文件):
- 脚本: common.py, models.py, 00_data_check ~ 09_figures, merge_preds.py, README.md, requirements.txt
- 结果: output/模型结果总表.md (v2 修正版), check/, backtest/ (summary+raw, 已排除 21MB npz),
  emerging/, ablation/, robustness/, service_materials/, figures/
- run_patches/: 对仓库根目录同名脚本的**修改版** (train_rssm_v3.py 增加 --seed/--split-year/--stoch-std;
  skwm_world_model.py 增加 stoch_std 消融开关+KL守卫+确定性推理修复; experiment_service_baseline.py /
  run_blind_experiment.py / filter_topic_noise.py / train_rssm_clean.py 为更新包脚本) —
  建议评审后合回主文件, 或直接以本目录版本为准。

## 二、推送步骤 (本机需已配置 GitHub 凭据)
```bash
# 1. 克隆/进入仓库 (若已有仓库则 pull)
git clone https://github.com/natebrashaf-rgb/skwm-world-model.git
cd skwm-world-model

# 2. 拷贝本包内容到仓库根目录
cp -r <本包路径>/experiments .

# 3. 添加忽略 (可选: 大中间产物不入库)
cat >> .gitignore <<'EOF'
# 实验中间产物 (可重算)
experiments/output/backtest/predictions_*.npz
experiments/output/dataset/
EOF

# 4. 提交
git add experiments .gitignore
git commit -m "feat: 实验流水线 — 时间回测/新兴主题/RSSM消融/稳健性/服务材料 (2026-08)

- 协议: 训练冻结<=2015, 验证2016-2020, 测试2021-2025; 全链路防泄漏
- 实验1: B0/B1/B2/M 回测 (1/3/5年, 6指标, 多种子均值±std+95%CI)
- 实验2: 新兴主题提前发现 (操作化定义+命中率/P@10/R@10/NDCG/虚假预警/提前时间+案例)
- 实验3: RSSM 消融 (完整/无随机/无动态/GRU)
- 实验4: 稳健性分层 (语言/频率/密度/成熟度/跨领域/时期×视野)
- 实验5: 盲评材料 9任务 A/B 随机化 + 空白评分表 (评分待真人)
- 结果: output/模型结果总表.md (v2 修正版, 含统计局限说明)
- 附注: XGBoost AUC=0.9408 无复现脚本, 标记未复现"

# 5. 推送
git push origin main
```

## 三、若本机无凭据 (当前状态: 无 gh CLI / 无 credential helper)
```bash
# 方式A: GitHub CLI 登录后执行上述步骤
winget install GitHub.cli && gh auth login && git push origin main

# 方式B: 配置凭据存储
git config --global credential.helper store
# 下次 push 时输入用户名+Token (Settings → Developer settings → Personal access tokens)
```
