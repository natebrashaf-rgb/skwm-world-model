### 4. 本地 vs 远端快照 SHA 对比（破案）
- 旧版（用户问的 2.36 vs 2.26）：git blob(3f9c86b, LF) = 2265652B = 远端；当时本地工作区
  = 2356182B(CRLF, b3e83b47)。blob 转 CRLF 后 SHA 完全还原 b3e83b47 → **同一份文件，行尾差异**
- 新版：远端 raw 下载 2263258B SHA 92a5d45a = git blob 一致；本地工作区 2353427B(CRLF) 不同，
  JSON 语义逐字段对比完全一致
- 根因：git core.autocrlf=true，Windows 工作区 CRLF → commit 时转 LF → GitHub 存 LF
- 影响：快照类文件以后比对 SHA 必须先统一行尾，或直接用 git blob
